# Airplane Simulator ✈️

A 3D first-person airplane simulator prototype made with Godot 4.

## Current playable prototype
- first-person 3D cockpit and walkable cabin
- get out of the pilot seat and walk with WASD
- airport ground, runway and fuel station
- manual refueling interaction
- engine, throttle, speed, altitude and fuel consumption
- dirty windshield and working wipers
- random rain
- flying birds: hitting one fails the flight
- desktop mouse look
- large on-screen buttons as the foundation for mobile controls
- tutorial hints
- fictional training aircraft and airport

## Current controls
Desktop:
- Mouse — look
- WASD — walk when out of the seat
- E — interact
- W/S while seated — pitch after takeoff
- Arrow Up/Down — throttle (legacy keyboard control)
- Esc — release mouse

On-screen:
- ◀ / ▶ — steer
- ТЯГА + / ТЯГА - — throttle
- ДЕЙСТВИЕ — interact / start engine / refuel
- ВСТАТЬ — leave/return to pilot seat
- ДВОРНИКИ — wipers

## Prototype flight
Start with a partly empty tank. Leave the seat, walk to the yellow fuel station, press action to refuel, return to the cockpit, start the engine, take off and avoid birds. Rain can begin during flight.

Open the project in Godot 4.x and press F5.
