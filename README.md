# Airplane Simulator ✈️

3D first-person airplane simulator prototype built with Godot 4.

## Game idea
You are the pilot. Fuel the aircraft yourself, enter the cockpit, start the engines, take off, keep the windshield clean, handle failures, avoid birds and land safely.

## First prototype
- 3D first-person cockpit
- procedural training aircraft interior
- working engine and throttle
- fuel consumption
- runway and takeoff
- altitude controls
- dirty windshield + wipers
- cockpit buttons
- first-flight tutorial
- ability to leave the pilot seat (foundation)

## Controls (desktop prototype)
- Mouse — look around
- E — interact / start engine / buttons
- Up / Down — throttle
- W/A/S/D — movement and flight controls
- Esc — release mouse

## Planned next
Mobile touch controls, walkable cabin, airport exterior, manual refueling hose, tools, failures, rain, birds, landing goals, money and aircraft progression.

## Run
Open the folder in Godot 4.x and press F6/F5.
